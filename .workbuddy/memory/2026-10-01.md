**改动只有 2 个文件（WXML + WXSS），零 JS 改动** —— 因为字形靠**祖先类**选，
总览卡片本来就是 `.q.q1`、详情头部本来就是 `.dhead.q1`，两处都命中同一条规则，不需要往 WXML 里传 key。

| 文件 | 改动 |
|---|---|
| `index.wxml` | 总览卡片 `.qtop` 里加一层 `.qrow`（图标 + 象限名同行）；详情页头部把 `hintpill` 提到 `.dmeta`（图标 + 胶囊一行），并挪到大数字**之上** |

### 图标怎么画的：内联 SVG 的 data URI 背景图

没有走「CSS 拼 border」那条老路 —— 火焰/闪电/灯泡/咖啡杯这类**具象图形**用 border 拼不出来或者很丑。
改用 `background-image: url("data:image/svg+xml,%3Csvg …%3E")`：WXSS 支持 data URI 背景图，
且 data URI 不经过文件协商，**绕开了「`<image>` 加载本地 .svg 在 Android 上不可靠」这个原始坑**
（§四那条禁的是 `<image src="*.svg">` 文件加载，不是内联 data URI）。
一个元素画完，没有内层 `<view>` → 也就没有「图标内 class 撞页面 class」的风险。

⚠️ 两个必须记住的点：

1. **颜色是烘焙进 data URI 的**（`%23d9303c`），不是 `currentColor` / `var(--qc)` ——
   data URI 是独立文档，拿不到外部 CSS 变量。所以**以后改 app.wxss 的四象限色，必须同步改
   `index.wxss` 里那 4 条 URL 的色值**（已写在注释里）。
2. 元素里的 `#` 必须写成 `%23`，`<`/`>` 写成 `%3C`/`%3E`（双引号改单引号可免转义）。

### 踩到的两个小坑

- **`.hintpill` 的 `margin-top:18rpx` 是它「独占一行」时的上方间距**，进了 flex 行必须清掉
  （`.dmeta .hintpill{margin-top:0}`），否则胶囊在行内被顶偏、整行高度虚高一截。
- **`.qrow .qname` 要写 `flex:1 1 auto;min-width:0`**：不清 `min-width:auto`，长标题会把图标挤出卡片。
- 顺手把详情页头部的**信息顺序**按设计图调了：原来大数字在最上、性质胶囊在最下，
  现在是「图标 + 胶囊」一组在上、大数字与「项待办」说明在下。这是用户设计图里明确摆的样子。

### 沉淀

- **CSS 图标分两条路线**：能用 border/伪元素拼的（加号、垃圾桶、箭头）继续自绘；
  **具象图形（火焰/灯泡/咖啡杯）用内联 SVG 的 data URI 背景图**，形状表达力差一个量级。
  两条都避开了 `<image>` + `.svg` 文件的老坑。
- **形状类改动必须渲染验证。** 「读代码看不出歪」和「量截图才发现偏心」是同一个道理：
  把验证前移成一张等尺寸 HTML + 无头截图，成本两分钟，收益是省掉一轮返工。
- **别让布局靠「刚好凑够」**：`.hintpill` 的 margin 是给「独占一行」写的，换个容器就得清 ——
  和 `.stat` 那条「别依赖外层内边距刚好凑够高度」是同一个教训。
